# 演示脚本

1. 启动后端和前端，打开 `http://localhost:5173`，确认服务在线，并展示紫金山固定森林场景、环境来源和等高线地图。
2. 输入演示地点/坐标，确认系统加载风速风向、地形坡度、道路、水源和 2+4+2 初始资源；说明无网络时会标注 `offline/demo-fallback`。
3. 上传首组 JPG/PNG 航拍影像或图片序列，展示缩略图、时间顺序、来源、视觉检测框和置信度；强调 fixture 不代表真实 YOLO。
4. 点击“启动智能研判”，依次展示火情感知、环境研判、FLP 负荷、人员状态（无人/有人/不确定）、W20/C6 资源匹配、SOC_need 和硬约束检查。
5. 展示动态八机资源池：R1–R2 侦察、E1–E4 灭火、S1–S2 支援。展示主方案、备选方案、任务分工、药剂/水源、时间区间和资源缺口；不要称为固定三架，也不要使用“18 分钟”单点结论。
6. 在方案处于“待确认”时点击“确认执行”，展示资源锁和审批事件；补充说明拒绝、调整、终止都会释放或更新资源，并记录原因。
7. 切换“无人机集群”“林区态势”“任务日志”，展示每架 UAV 的 SOC、状态、模块、剩余药剂、信号和健康度，以及紫金山环境信息。
8. 点击“执行下一轮监测”或提交反馈轮次，展示第 1/2 轮 FLP、SOC、药剂、库存和 UAV 状态对比。模拟风速升档、FLP 上升超过 20% 或 SOC 低于返航阈值，展示暂停原方案、重规划和新版本。
9. 展示有人分支时 S 通信/广播/路线指引与 E 保护资源；无人分支时 S 转物资/电池运输和后备监测；不确定时先复核，不把全部资源投入远端火点。
10. 任务达到控制目标后打开报告归档，展示输入、环境来源、方案版本、审批事件、反馈轮次、调度变化、资源消耗和最终结论。
11. 收尾说明当前是规则仿真：真实 YOLO/VLM、在线 GIS/气象、复杂避障、真实飞控和持久化数据库属于后续接入能力。
