# 算法说明

当前 MVP 使用可解释、可复算的规则模型。地图可按 100 m² 网格展示，内部将火情表示为 FLP（Fire Load Points）负荷，不使用固定“每小时灭多少平方米”或“每升水对应多少面积”的旧口径。

## 火情负荷

对网格 `i`：

```text
B_i = 10 × I_i × K_fuel × K_wind × K_slope
B_total = ΣB_i
```

火势强度、燃料、风和坡度均来自结构化观测/环境数据。增长按分钟折算：

```text
B_next = max(0, B_now + G × Δt / 60 − ΣS)
```

## 药剂有效能力

```text
S = Q_agent × κ_agent,scene × η_drop × η_weather
```

植被火默认 W20 水剂（κ=1.00 FLP/L）；C6 CO₂ 不用于开放森林地表火，仅用于局部设备、电气热点或小范围复燃点。命中、风和遮挡导致效率折减。不同架次不混装 W20/C6。

## SOC 与可行性

耗电率以 `%/h` 配置，内部每分钟计算：

```text
ρ_load = m_task / m_capacity
r = r_mode × (1 + 0.45ρ_load + 0.20f_wind + 0.10f_climb) + r_aux
ΔSOC = r × Δt / 60
SOC_need = SOC_outbound + SOC_task + SOC_return + SOC_reserve
```

方案必须满足：药剂兼容、载荷不超限、路线可达、健康度合格、SOC 足够且预计返航 SOC ≥25%。低于阈值时返航、换电、换机或输出资源缺口。

## 调度与评分

资源池为 R1–R2、E1–E4、S1–S2。至少保留一架 R 在线；E 子群枚举 1–4 架组合；有人时保留 S 通信/指引和 E 保护资源，unknown 时先复核；无人时 S 转后勤、通信或后备侦察。流程是“候选生成 → 硬约束过滤 → 5 分钟离散仿真 → 多目标评分”：

```text
J = 0.40T_norm + 0.30B_residual + 0.15E_norm + 0.10M_norm + 0.05N_change
```

`J` 越小越优；不可行时必须返回 `resource_gap` 和备选动作，不生成无依据的确定完成时间。

## 闭环与时间

系统按 1 分钟推进飞行、SOC、喷洒、增长、返航、通信、库存和补给状态；界面每 5 分钟展示轮次。FLP 上升超过 20%、风速升档、预计返航 SOC 低于 25%、药剂/库存不足、通信或健康度下降、新发现人员、用户改约束时立即重规划。

输出仿真时间区间，取决于 FLP、增长率、机群组合、路线、补给和约束。旧的“18 分钟”单点结论已不再作为系统口径。
