# 模型选型说明（model-selection）

- **选型结论**: glm-4.6v-flash（智谱 BigModel 标准API，免费档）
- **选型日期**: 2026-09-06（第1天冒烟验证 + 第2天12组案例全量实测）

## 一、为什么选它

| 维度 | 实测证据 | 结论 |
|---|---|---|
| 成本 | 免费模型，两天48次调用共约14万tokens，成本 ¥0 | 学生团队零成本 |
| 视觉理解能力 | 12组案例内容检查 77/85=90.6%；明火/烟分级、人员/建筑识别、夜间弱光火带全对 | 达标 |
| 防幻觉纪律 | 只见烟→smoke_only；无火+假YOLO框→仍判无火并上报矛盾；9类红线词48次0违规 | **关键优势**：不越权、不编造 |
| 结构化输出 | vlm-analysis-v1 全字段JSON可稳定产出（v4提示词下格式问题显著收敛，剩余可服务端根治） | 达标 |
| 响应速度 | 纯模型耗时中位19秒（最快10秒，最慢51秒） | 可接受，注意这是推理型模型（reasoning占completion 69%） |
| 接入难度 | OpenAI风格 chat/completions，Bearer鉴权，图片Base64直传 | 开发者1天内可接入 |

## 二、已知限制（接入时必须有对策）

1. **晚高峰限流（最大工程风险）**：免费档 19:00–22:00 429密集，两天11次调用失败于限流/空响应。对策：错峰调用、退避重试[15,40,90,150]秒、HTTP 200空响应按失败重试（详见 evaluation-results.md §4.4、§7）。
2. **两个能力短板**：水源漏检（0/2）、图片质量自评乐观（0/2）。对策：water/image_quality 字段只作参考，不单独依赖（handoff-checklist §三）。
3. 推理型输出：completion 中 69% 是 reasoning tokens，max_tokens 需留足（2048 实测够用）。

## 三、备选与升级路径

| 选项 | 情况 | 建议 |
|---|---|---|
| glm-4.6v（付费版） | 同厂更强版本，限流配额更高 | 若比赛演示需要高峰时段稳定调用，可升级并**用本套12案例复测**（脚本可复跑：`python scripts/02_run_cases.py --prompt-version v4`） |
| 其他多模态API | 未测 | 任何更换都须过同一套12案例+判卷，不可直接替换 |
