# 需求摘要

## 1. 项目目标

系统面向森林火灾应急指挥演示，围绕紫金山固定森林区域，完成“感知—研判—调度—审批—执行模拟—反馈重规划—报告归档”的可视化闭环。输入包括地点或坐标、图片/图片序列、环境快照、2+4+2 虚拟机群状态和物资库存；输出包括火情类型与 FLP、风险解释、资源需求、候选调度、审批状态、轮次变化和归档报告。

## 2. 资源与规则边界

- 资源池为 2 架侦察 R1–R2、4 架灭火 E1–E4、2 架支援 S1–S2；子群是角色层级，每架 UAV 独立记录，按需出动。
- 火情负荷以 FLP 表示，地图可用 100 m² 网格呈现，但不把旧的固定面积/升水能力作为核心规则。
- W20 水剂用于一般植被火；C6 CO₂ 仅用于局部设备、电气热点或小范围复燃点，同一架次不混装。
- SOC 以 `%/h` 参数录入、按 1 分钟内部更新；每 5 分钟形成反馈轮次；预计返航 SOC 必须不低于 25%。
- 先满足药剂兼容、载荷、SOC、路线、健康度和人员保护等硬约束，再进行时间、风险、耗电和物资评分。
- 时间输出为仿真区间或资源缺口，不硬编码旧的“18 分钟”单点结论。

## 3. 用户与自动化边界

用户主要输入地点、连续图片、可选时限/资源限制，并确认、拒绝、调整或终止方案。系统自动读取视觉、紫金山环境、道路水源、机群和库存；人员状态为 `confirmed`、`absent` 或 `unknown`，不确定时先复核。智能体负责调用 Skill/Tool 和解释，确定性 Tool 负责关键数字。

## 4. MVP 范围

必须支持：固定场景环境查询、视觉 fixture 或模型适配接口、FLP 风险评估、W20/C6 资源匹配、2+4+2 动态调度、有人/无人/不确定分支、方案审批闭环、5 分钟反馈重规划、任务事件和最终报告归档。

真实飞控、在线气象、全国 GIS、复杂三维仿真、连续视频流、生产级队列和持久化数据库不属于当前 MVP；环境离线回退必须明确标注来源。
