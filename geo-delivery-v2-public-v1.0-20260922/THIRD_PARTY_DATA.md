# 第三方数据与公开发布说明

本文件说明 `geo-delivery-v2` 中各数据源的来源、用途和公开仓库分发策略。项目代码、元数据和项目自建成果的许可，不会自动改变第三方数据原有的权利状态。

## 数据源与仓库策略

| 数据模块 | 主要来源 | 本项目用途 | 公开仓库策略 |
|---|---|---|---|
| SRTM DEM、坡度、坡向 | NASA/USGS SRTMGL1 v003 | 南京地形分析 | 可按来源要求发布派生成果并保留来源说明 |
| 地表覆盖与江苏林木概览 | ESA WorldCover 2021 v200 | 地表覆盖和林木覆盖统计 | 按 CC BY 4.0 署名要求发布 |
| 道路、水体、节点和设施候选 | OpenStreetMap contributors / Geofabrik | 路网、水源和设施候选分析 | 按 ODbL 1.0 署名；超大原始文件和大体量派生文件不直接进入普通 Git 历史 |
| 气象数据 | Open-Meteo | 当前、24小时预报和72小时回放 | 保留 Open-Meteo 来源及相应许可说明 |
| 江苏省、13个设区市和南京行政边界 | 国家地理信息公共服务平台（天地图） | 地图可视化、裁剪、区域索引和内部空间处理 | **不在公开仓库分发原始或可基本还原完整行政边界的矢量** |
| 云台山、宁镇丘陵东段、宜溧山地、环太湖丘陵 | 本项目依据 SRTM、WorldCover 和公开地理描述派生 | 规划展示 | 可以公开，但必须标明非官方、非行政、非执行调度边界 |

## 天地图行政区划数据

行政区划数据下载界面标注“该数据仅供地图可视化使用”。因此本项目采用以下保守处理：

- 本地完整交付包可以将相关边界用于地图可视化和内部空间处理；
- 公开 GitHub 仓库不分发天地图下载的原始行政区划矢量；
- 公开仓库也不分发能够基本还原江苏省、13个设区市或南京完整行政边界的派生矢量；
- 来源元数据、处理脚本、统计结果和渲染后的 QA 图片可以保留；
- 公开空间入口使用 `data/overview/areas_public.geojson`，其中只包含4个项目派生规划展示区；
- 本地完整空间入口 `data/overview/areas.geojson` 受公开发布排除规则保护。

详细溯源记录见 `metadata/nanjing_boundary_provenance.json`。

## OSM 署名

道路、水体和设施候选包含来自 OpenStreetMap contributors 的数据。公开展示、再分发或产生衍生数据库时，应保留 OpenStreetMap 署名并遵守 ODbL 1.0。原始江苏 PBF、GPKG，以及超过普通 GitHub 文件限制的道路和节点成果，不直接提交到普通 Git 历史。

## 项目派生规划区

四个规划展示区是本项目研究和演示使用的概览范围，不是法定行政边界、自然地理标准边界、保护区边界或可执行调度区域。其公开使用不得省略这一限制说明。

## 本地包与公开仓库的差异

本地完整交付包用于数据处理、QA 和平台内部接入；公开仓库用于代码、方法、元数据、轻量成果和可公开派生成果的协作。公开仓库缺少受限或超大数据文件属于设计结果，不代表本地交付包不完整。
